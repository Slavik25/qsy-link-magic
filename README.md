# QSY

Plataforma de biolinks premium: perfiles personalizables, enlaces, insignias, música, módulos de gaming y estadísticas en tiempo real.

## Desarrollo

```bash
bun install
bun run dev
```

La app corre en `http://localhost:8080`.

## Stack

- React 19 + TanStack Start (SSR + server functions)
- Tailwind CSS v4
- Backend gestionado (base de datos, auth, storage)
